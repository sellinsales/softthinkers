# SoftThinkers Workspace

This repository is now the working base for:

- the `LingoHunt` mobile app
- the shared PHP backend for app data
- the public `softthinkers.com` website scaffold

## Structure

```text
app/                  Expo Router mobile app
backend/              Shared PHP + MySQL API
softthinkers-site/    Public website for hosting, development, games, and portfolio
```

## Current focus

- `softthinkers.com` as the main public-facing brand site
- `lingohunt.softthinkers.com` as an app/backend subdomain
- a shared backend that can later support multiple child-focused apps

## Website scope

The website scaffold is intentionally simple, but it is built to present:

- hosting packages
- web and app development services
- game development highlights
- portfolio categories such as ride hailing, taxi booking, marketplaces, and learning apps

It now also includes:

- package consultation forms
- lead capture persistence support
- a portal direction page for future client accounts and renewals

## Deployment note

The site is shared-hosting-friendly and uses plain PHP, HTML, CSS, and minimal JavaScript-free rendering.
